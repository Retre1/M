## TL;DR — три столпа, без которых 0%

Чтобы любая trading-система зарабатывала, нужны **три** вещи одновременно. Если хоть одна слабая — система убыточна:

```
        EDGE  +  EXECUTION  +  DISCIPLINE  =  PROFIT

   Доказанное      Надёжная       Соблюдение
   преимущество    инфра          правил без
   на OOS          без потерь     эмоций
   данных          сигналов
```

**Если у тебя сильный EDGE но слабая EXECUTION** → теоретическая прибыль уезжает в spread, slippage, fail-orders. Слил.

**Если сильная EXECUTION но нет EDGE** → отлично исполняешь убыточную стратегию. Слил.

**Если есть EDGE и EXECUTION но нет DISCIPLINE** → ручные override'ы, отключение SL когда страшно, увеличение позиций после loss streak. Слил.

У тебя сейчас:
- 🟡 **EDGE** — НЕ ДОКАЗАН (все 8 чекпоинтов либо мертвы, либо теряют). Baselines нашли потолок ~+0.7 Sharpe на full period.
- 🟢 **EXECUTION** — есть инфраструктура (executor, risk manager, MT5 client), нужна валидация на demo.
- 🔴 **DISCIPLINE** — ноль данных (paper trading 0 дней).

**Главный недостающий элемент — EDGE.** Без него остальное бессмысленно.

## Минимально жизнеспособный путь к первой прибыли

### Honest вариант: гибрид Donchian-LO + RL

Я НЕ верю что RL модель станет топовой за 4-6 недель работы. Шанс ~25-35%. Но **Donchian-LO уже сейчас имеет real edge** (+0.05 Sharpe при retail спреде 3.5 пип, +0.165 при 1.5 пип). Это **уже работающая стратегия**, нужна только обвязка.

**Параллельный путь = максимум expected value:**

```
Week 1 ─┐
        ├─ Donchian-LO production code (без RL)
        ├─ MT5 demo connection + Telegram alerts
        └─ Cloud GPU rental + RL training с фиксами
        
Week 2-4 ─┐
          ├─ Donchian-LO собирает paper-trading статистику (Track A)
          ├─ RL завершил 1-2 итерации тренинг + walk-forward (Track B)
          └─ Сравниваем оба на тех же fold'ах
          
Week 5-6 ─┐
          ├─ Принимаем решение: какая стратегия в production
          ├─ Если RL > Donchian-LO → используем RL (но Donchian как fallback)
          └─ Если RL ≤ Donchian-LO → используем Donchian-LO
          
Week 7-12 ─┐
           ├─ Micro-live на $200-300 cent account
           ├─ Лучшая из выбранных стратегий
           ├─ Только наблюдение, никаких ручных вмешательств
           └─ Если +0% после 30 дней → депозит до $1k
```

### Альтернативные пути (одиночные)

#### Путь "только RL" (риск 65-75% что не зайдёт)
- Меньше работы (одна стратегия)
- Полностью зависит от того, дадут ли фиксы edge
- Если не дают → 1.5 месяца впустую

#### Путь "только Donchian-LO" (риск 45-55% что не зайдёт)
- Гарантированно работает (proven edge на ваших данных)
- Низкий потенциал доходности (~5-15% в год реалистично)
- Нет automated improvement потенциала

#### Путь "Donchian-LO + RL параллельно" ⭐ РЕКОМЕНДУЮ
- В 2 раза больше работы первый месяц
- Если RL не зашло → есть Donchian-LO в живой торговле
- Если RL зашло → переключение на лучшую стратегию через 6 нед
- Максимальный expected value

## Что НЕ принесёт прибыль (антипатерны)

Антипример того, как ритейл-трейдеры **гарантированно** сливают:

1. ❌ **Запустить текущую модель в live "проверить"** — все 8 чекпоинтов мертвы. Зальёшь $200-300 за 2 недели.
2. ❌ **Добавлять новые features** — feature selector уже отверг 37 из 52. Больше шума не поможет.
3. ❌ **Hyperparameter tuning без edge** — 50 trials Optuna на сломанной архитектуре дадут локальный максимум, не edge.
4. ❌ **Скачивать чужие готовые EA** — 99% open-source forex EA убыточны на realistic costs (validation сделал бы это очевидным).
5. ❌ **Leverage > 10:1 на H1/H4** — 2-3 убытков подряд = margin call.
6. ❌ **Increase risk after losses** — классический gambler's fallacy. После DD 5% **уменьшать** размер, не увеличивать.
7. ❌ **Manual override SL** — если эмоционально не можешь видеть SL — вообще не торгуй.
8. ❌ **Запустить и забыть** — даже automated bot нуждается в daily check (drift detection).

## Главный вывод (без воды)

Чтобы проект **реально заработал**, в порядке убывающей важности:

1. **GPU** + **тренинг с фиксами** + **honest walk-forward + baseline** = $10 + 1-2 дня работы. Без этого — НИЧЕГО.

2. **Donchian-LO в production** = 1-2 недели кода. Real edge already exists. Это твой Plan B и одновременно baseline для сравнения с RL.

3. **30 дней paper trading** = 1 месяц времени. Не код, а **дисциплина**. Без paper не идти в live ни при каких условиях.

4. **Hard kill switch + Telegram alerts** = 2-3 дня. Защита от катастрофического слива.

5. **Reality acceptance**: твой capital $1k → реалистичный таргет $100-250 в год после ~3-6 месяцев работы. Если ожидания выше — не торгуй вообще.

**Самое короткое расстояние до первой реальной прибыли:**
6-10 недель упорной работы по гибридному пути выше. Если торопить — гарантированный слив.
